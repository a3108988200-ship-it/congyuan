# Conrad Notes · 每日便签

云端便签工作台：自由安排每日任务、勾选进度、记录成果、日记、复盘和日历提醒。每天从空白清单开始。

## 项目结构

- `frontend/`：任务界面、样式和交互。
- `worker/`：Sites Worker API、账号隔离和云端保存逻辑。
- `.openai/hosting.json`：通用 Sites 存储配置，未绑定任何线上站点。
- `scripts/`：构建、构建检查和本机预览。
- `tests/`：使用合成记录验证身份隔离、迁移和并发保存。

## 构建与测试

使用 Node.js 22 或以上版本，无第三方依赖：

```sh
npm test
npm run preview
```

预览前先构建；预览服务只绑定 `127.0.0.1:8791`，使用模拟账号和内存存储，退出后不保留记录。

## 部署说明

正式运行需要 Sites 的登录入口和 R2 `BUCKET` 绑定。部署时绑定自己的私有站点，再构建和发布。应用通过平台提供的已验证身份隔离数据；本机预览的模拟身份不用于线上。

本仓库仅保存源码，不包含个人任务、日记、账号凭据、数据库或线上运行密钥。迁移数据应由站点管理员通过私有运行配置管理。后续可补充真机登录和跨设备同步的验收记录。
